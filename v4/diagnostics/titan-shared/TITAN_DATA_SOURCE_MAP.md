# Titan Data Source Map

| 层 | 当前来源 | 用途 | 限制 |
|---|---|---|---|
| 赛程/比分 | Titan007 公开列表页快照 | 比赛身份、开赛时间、状态、赛果 | 仅 `state=-1` 进入已完场历史 |
| 亚洲盘 | Titan007 公开聚合/展示公司 | 开盘、即时盘、水位、市场偏离 | 不进入 FFL；单源不声称多公司共识 |
| 欧赔 | Titan007 百家均值/公开字段 | 去水 1X2、CMFL | 不进入历史时点之外的特征 |
| 大小球 | Titan007 公开字段 | CMFL 总进球约束 | 缺失则 CMFL 仅用 1X2 网格拟合 |
| 排名/阶段 | 列表页字段 | AS-OF 排名证据 | 仅按抓取时间生效，缺细表字段为 NULL |
| 球员/伤停/首发 | 当前无可靠结构化覆盖 | 可选上下文 | NULL，不脑补 |
| 公共资金流 | 当前无同盘口可靠流量 | Public Pull | 标记 `MISSING`，不冒充真实资金流 |

抓取遵守公开页面边界：HTTP 缓存 5 分钟、全局最小请求间隔 0.30 秒、详情页最多 3 个并发、urllib 最多 2–3 次退避重试，失败时才使用正常 Chromium 访问同一公开页。不绕过验证或访问控制。
